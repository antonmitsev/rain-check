# RainCheck

Минимално уеб приложение с два въпроса: **„Вали ли?“** и **„Докога ще вали?“**

## Цел

RainCheck взима местоположението на потребителя, заявява текущите валежи и краткосрочната прогноза и връща кратък отговор на български.

## MVP

- Геолокация чрез Browser Geolocation API (само след разрешение).
- Ръчно въвеждане на град, ако достъпът до местоположението е отказан.
- Два бутона: **Вали ли?** и **Докога ще вали?**
- Данни от [Open-Meteo](https://open-meteo.com/) за некомерсиална употреба, съобразно условията на услугата.
- Кеширане на резултата за до 10 минути.
- Без регистрация, база данни и платен AI API в MVP.
